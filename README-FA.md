# داشبورد مدیریت پرتفوی TOSAN TECHNO

این بسته شامل کد منبع داشبورد و فایل نمونه ورود اطلاعات اکسل است.

## اجرای محلی

پیش‌نیاز: Node.js نسخه 22.13 یا بالاتر و pnpm.

در پوشه پروژه اجرا کنید:

```bash
pnpm install
pnpm dev
```

سپس نشانی محلی که ترمینال نشان می‌دهد (معمولاً `http://localhost:3000`) را در مرورگر باز کنید.

## ورود داده

از داخل داشبورد، بخش «ورود داده اکسل» را باز کنید، فایل نمونه را بگیرید، ردیف‌های نمایشی را با داده‌های خود جایگزین کنید و فایل را بارگذاری کنید.

## نکته

این بسته برای اجرا به نصب وابستگی‌ها نیاز دارد و فایل اجرایی مستقل نیست. نام مدیرانی که از داخل داشبورد ویرایش می‌شوند و تنظیمات برخی نماها در نسخه فعلی فقط در مرورگر همان دستگاه ذخیره می‌شوند.
